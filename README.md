# Personal Finance Tracker

This repository contains a simple Python-based finance tracker.
It models transactions and calculates monthly balances.

## Features
- Transaction data structure
- Income and expense analysis
- Clean and simple design

## Purpose
This project shows clean Python design and basic data modelling skills.
It focuses on clarity, correctness, and maintainability.

## Tools used
- Python
- Dataclasses
